# 🎮 Simon Game

A web-based memory game inspired by the classic *Simon Game*. Test and sharpen your memory by repeating increasingly complex sequences of lights!

---

## 📌 About The Project

The Simon Game is a classic pattern-matching memory game. The game generates a random sequence of color flashes. The player must replicate the exact sequence. With every successful round, the sequence becomes longer and faster. One wrong click ends the game!

---

## ✨ Features

- ⚡ **Dynamic Sequence Generation:** Randomly generated patterns that expand after each successful level.
- ❌ **Game Over Feedback:** Screen flash animation when a wrong sequence is entered.
- 📱 **Responsive UI:** Clean, intuitive interface playable across modern browsers and devices.

---

## 🛠️ Tech Stack

- **HTML5:** Structure and markup of the game elements.
- **CSS3:** Styling, keyframe animations, and color themes.
- **JavaScript / jQuery:** Core game logic, sequence tracking.

---

## 🎮 How to Play

1. **Start:** Press any keyboard key (or tap screen) to start the game.
2. **Observe:** Watch the highlighted color.
3. **Repeat:** Click the color buttons in the exact order shown by the game.
4. **Advance:** Each correct round adds one new color step to the sequence.
5. **Game Over:** Clicking an incorrect button ends the game. Press any key to try again!
